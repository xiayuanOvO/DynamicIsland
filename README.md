# 灵动岛 · Dynamic Island

使用 Go + [MyGo](https://github.com/egoist/mygo) 原生 UI 实现的桌面文件中转岛。界面由 Go 绘制，不需要浏览器、Node.js 或 WebView2。

默认浮在屏幕顶部中央。没有未完成待办、暂存文件且媒体未播放时，收起为一行胶囊，从左到右显示表情、天气、设备电量和本地时间。两只黑色椭圆眼睛会眨眼、显出困倦或笑意，偶尔看向鼠标。单击展开，鼠标移开约 200 毫秒后收起。按住收起的灵动岛或展开面板顶部可拖动位置。

在「设置 → 空闲」拖动项目可调整显示顺序，用开关可单独隐藏项目。聚焦开关后，也可以用 ↑ 或 ↓ 移动项目。全部关闭时会保留可点击展开的空闲胶囊。

macOS 和 Windows 默认开启「设置 → 应用 → 全屏时隐藏灵动岛」。前台应用全屏时，灵动岛和歌词会自动隐藏，退出全屏后恢复。关闭此项可在全屏时继续显示灵动岛。

空闲胶囊用环形进度显示设备电量，展开后可查看百分比和完整设备列表。闪电表示正在充电。macOS 显示本机电池和已连接的蓝牙设备。系统缺少读数时，打包版会尝试读取标准蓝牙电池服务（如 ROG Keris Wireless AimPoint）或 OPPO Enco Free4 的电量服务，首次使用可能需要允许蓝牙访问。左右耳和充电盒有独立读数时会分别显示。未知电量在空闲胶囊里显示为虚线环，展开后显示「—」。Windows 显示本机电池。

空闲胶囊通过图标和温度显示天气。天气默认按网络 IP 估算位置。可在「设置 → 天气城市」搜索并选择城市，或恢复自动定位。搜索结果以行政区区分同名城市，天气无法获取时继续显示时间。 [天气数据由 wttr.in 提供](https://github.com/chubin/wttr.in) · [城市搜索由 Open-Meteo 提供](https://open-meteo.com/en/docs/geocoding-api) · [城市数据来自 GeoNames](https://www.geonames.org/) · [城市数据许可 CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

## 运行和构建

主要面向 Windows 11 22H2 及以上版本。Windows x64 使用系统合成器模糊灵动岛背后的桌面和窗口，并将效果裁剪到灵动岛的圆角轮廓内。无法创建模糊背景时使用实色渐变。macOS 使用 MyGo 的系统玻璃材质，Linux 使用渐变背景。

需要 Go 1.27.3+。`go.mod` 固定 MyGo v0.9.2；开启 `GOTOOLCHAIN=auto` 时，Go 会按需下载所需工具链。

```powershell
go mod download
go run .
```

开发时可运行 `go tool mygo dev`，修改 Go 代码后自动重新构建并启动。在 macOS 上首次开发前运行 `./scripts/build-macos.sh --prepare-media`，开发版与发布版会打包同一份媒体适配器。

构建无控制台窗口的 Windows 程序：

```powershell
.\scripts\build.ps1
```

输出：`dist\DynamicIsland.exe`。也可以直接执行：

```powershell
go build -trimpath -ldflags "-H=windowsgui -s -w" -o dist/DynamicIsland.exe .
```

## 发布和应用内更新

正式安装版在启动后和运行期间自动检查 GitHub Releases，也可在「设置 → 应用」选择「检查更新」。检查时圆环旋转，发现新版本后会直接下载安装，圆环按下载进度填充。安装完成后选择「重启应用」即可使用新版本。后台发现新版本时会提示，也可以选择以后自动下载更新，下次启动时生效。更新会验证签名，并保留设置、待办和暂存记录。现有版本需先手动安装一次支持更新的版本，之后即可在应用内更新。

### 一次性配置

1. 在项目目录运行 `go tool mygo keygen`。将 `mygo-update.key` 保存在仓库外并备份，所有后续版本使用同一套签名密钥。
2. 在 GitHub 仓库的 **Settings → Secrets and variables → Actions** 添加以下配置。

| 类型 | 名称 | 值 |
| --- | --- | --- |
| Variable | `UPDATE_PUBLIC_KEY` | `mygo-update.pub` 的内容 |
| Secret | `MYGO_UPDATER_PRIVATE_KEY` | `mygo-update.key` 的内容 |

### 发布新版本

以下命令会把当前提交标为 `v0.2.0` 并推送标签。

```sh
git tag v0.2.0
git push origin v0.2.0
```

标签决定应用版本号。GitHub Actions 会构建 Windows x64 安装程序、macOS 通用版磁盘映像，以及两个平台的更新包和清单。两个平台都构建成功后，到本仓库的 Releases 打开草稿，确认产物齐全并发布为最新正式版。应用会跳过草稿和预发布版本。若要在应用内展示更新说明，可在打标签前把对应版本的 `## 0.2.0` 章节写入 `CHANGELOG.md`。

应用需要对安装位置有写入权限。现有构建流程使用 macOS 临时签名，初次分发的磁盘映像未经 Apple 公证，Windows 安装程序也没有 Authenticode 签名。更新包使用独立的 MyGo 签名。

## 媒体播放

系统有当前媒体时，展开面板会在暂存区上方显示封面、曲名、艺人、播放进度和可用的播放控件。点击或拖动进度条可跳转，具体支持取决于播放器。媒体播放时，收起的胶囊也显示频谱。柱高跟随系统音频，左侧低频，右侧高频。macOS 14.2 及以上首次使用需要允许系统音频录制，只在内存中计算频谱，不保存音频。

- Windows 11 通过系统媒体会话读取和控制播放，使用系统自带的 Windows PowerShell。网易云音乐未向系统提供播放进度时，灵动岛在本机读取近期播放日志，用当前曲目的播放、暂停和跳转记录同步进度和歌词。日志缺少当前曲目的有效记录时，灵动岛根据检测到的播放状态估算时间，总时长可从网易云曲库补充。估算时，歌曲中途接入、拖动进度或单曲循环可能造成偏差。
- macOS 发布版内置媒体工具，用户打开应用即可使用。用 `./scripts/build-macos.sh` 在装有 Go、Xcode 命令行工具和 CMake 的 Mac 上构建通用版，产物位于 `dist/`。直接用 `go run .` 启动时没有随包媒体工具。

在托盘或灵动岛右键菜单打开「设置」，可为律动柱选择默认蓝灰色、自定义颜色或跟随海报。设置自动保存到与 `shelf.json` 同级的 `settings.json`。

「音乐卡片风格」可在默认的频谱卡片和大封面卡片之间切换，设置中会同步预览。大封面卡片左侧展示专辑封面，右侧显示曲目信息、进度条和播放控件。

收起时，同步歌词显示在胶囊下方。当前句高亮，超出单行宽度时最多折成两行，前后句各占一行。超过两行时，第二行按当前句剩余的播放时间调整横向滚动速度，尽量在换句前露出句尾。在「设置 → 媒体」可调整歌词字号（16–28，默认 21）和当前句的高亮颜色（默认白色），并在「歌词过渡」选择上移（默认）、淡入、缩放或关闭过渡。调整会即时生效并自动保存。开启系统「减少动态效果」时，歌词直接换句，超长句以省略号收尾。在 macOS 和 Windows 上，将灵动岛拖到屏幕左侧或右侧边缘松手，灵动岛会收成小圆球，在屏幕内露出一半，歌词显示在朝向屏幕内侧的一边。可在设置里关闭「显示歌词」。在线歌词按曲名和艺人匹配，依次查询 LRCLIB、网易云音乐、QQ 音乐和酷狗音乐。曲名写法有差异时，还会核对专辑和时长。也可将 UTF-8 编码的 `歌手 - 歌名.lrc` 放在 `shelf.json` 同级的 `lyrics` 文件夹，程序优先读取本地文件。

在线获取的同步歌词会保存在 `shelf.json` 同级的 `lyrics-cache` 文件夹，重启后也可离线复用。在线、缓存和本地 LRC 歌词中的繁体中文会在显示前自动转为简体，保留原始文本和时间轴。可在「设置 → 媒体 → 歌词缓存」查看占用大小（MB）并清理在线缓存。手动添加的 `.lrc` 文件保存在独立的 `lyrics` 文件夹。

## 待办事项

点击展开面板中的半宽待办卡片，可在岛内打开全宽列表并新建待办。托盘菜单中的「待办事项…」也会打开同一列表。点击事项名称可修改或删除，勾选后移入「已完成」，取消勾选可恢复。半宽卡片最多同时显示三条未完成事项，滚动可查看更多，也可直接勾选完成。列表优先显示截止时间最早的事项，无截止时间的排在其后。

截止时间可选。开启后默认提前 15 分钟提醒，也可选提前 5 分钟、30 分钟、1 小时、准时提醒或不提醒。应用运行时通过系统通知提醒，隐藏灵动岛后仍然有效。退出期间错过的提醒会在下次启动时补发给仍未完成的事项。macOS 使用打包的应用并允许系统通知即可接收横幅。待办和提醒记录保存在与 `shelf.json` 同级的 `todos.json`。

## 剪贴板历史

在「设置 → 剪贴板」开启「记录剪贴板」后，可从灵动岛展开面板、托盘菜单或全局快捷键打开剪贴板历史。默认快捷键为 `Alt + Shift + V`（macOS 为 `Option + Shift + V`）。应用运行时会记录复制的纯文本和图片，重复内容只保留一条，最近复制的排在前面。图片显示缩略图和尺寸，点击记录可重新复制完整文本或原尺寸图片。可删除单条记录或清空历史。

在「设置 → 剪贴板 → 快捷键」点击当前组合并按下新快捷键，按 `Esc` 可取消。用快捷键打开的面板失去焦点时会收起。

打开历史时先显示最新的 50 条记录，滚动接近底部或按 `↓` 到页尾会自动加载下一页。输入关键词时，从全部未过期记录中进行全文匹配，结果同样按页加载。输入「图片」可查看图片记录。用 `↑` / `↓` 选择结果，按 `Enter` 复制并关闭面板。用全局快捷键从其他应用打开时，macOS 和 Windows 会尝试把选中内容粘贴到打开前的输入位置。macOS 需要在「系统设置 → 隐私与安全性 → 辅助功能」允许灵动岛。Linux 或系统阻止自动粘贴时，内容仍保留在系统剪贴板中，可手动粘贴。

记录默认关闭。文字、PNG 图片和剪贴板设置保存在与 `shelf.json` 同级的 SQLite 数据库 `clipboard.db`。首次启动时会迁移 `clipboard.json` 和 `clipboard-images` 中已有的未过期记录。关闭记录会隐藏入口并停用快捷键，重新开启后可继续查看仍在保留期内的历史。

记录从最近一次复制起保留 90 天，文字和图片合计最多 10,000 条，超出时移除最旧的记录。应用在启动、运行期间以及写入新记录时清理过期记录。每条文本最多 32 KiB，每张图片最多 16 MiB 和 2400 万像素。应用会跳过空白及标记为私密或临时的内容。macOS 如果提示剪贴板访问权限，允许后方可记录。

## 文件中转

1. 从桌面或资源管理器把文件拖到灵动岛上，松开鼠标完成暂存。支持多个文件和文件夹，重复路径自动去重。暂存区有文件时才显示。
2. 文件以三列紧凑玻璃卡片排列，图片直接显示等比裁剪的缩略图，其他文件显示系统关联的类型图标。每张卡片还显示最多两行文件名、文件类型和大小；超过两行卡片时可在文件区内滚动。把卡片拖到 QQ、微信聊天窗口，或其他支持接收文件的应用。
3. 悬停卡片时显示左上角选择框和右上角移除按钮。勾选多个卡片后，可拖动其中任意选中卡片批量传递；底部“拖出”按钮可拖出选中项，没有选择时拖出全部。
4. 点击复制按钮后，到目标应用粘贴，也可以传递文件。
5. 右键卡片可复制、在文件夹中显示或移除；双击卡片可定位原文件。

托盘菜单可添加文件或文件夹。程序也接受命令行文件路径，例如 `DynamicIsland.exe "D:\资料\说明.pdf"`；重复启动会将路径交给已运行的实例。

缩略图与图标在后台按需加载，仅预加载可见及临近的卡片，内存缓存最多 96 项。Windows 优先使用系统缩略图服务；PNG、JPEG、GIF、WebP、BMP、TIFF 有内置解码回退，SVG 可直接绘制，HEIC、HEIF、AVIF 等依赖系统的缩略图支持。读取失败时显示对应类型的备用图标。重复拖入图片可刷新其缩略图。

暂存区保存的是本地路径引用，不复制文件内容。移除和拖出都不会删除或移动原文件。列表保存在 `%APPDATA%\DynamicIsland\shelf.json`，重新打开时恢复，失效路径会跳过；运行期间失效的路径会在拖出或复制时提示，可手动移除。

文件拖放使用 MyGo 的系统原生接口；Windows 通过 OLE / `CF_HDROP` 传递文件列表。QQ、微信等目标应用是否接受文件、文件夹或多文件，以及是否要求确认发送，由目标应用决定。程序报告“已交给目标应用”表示拖放被接收，不表示消息已经发送。不支持邮件附件等尚未落盘的虚拟文件。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + Space` | 全局展开 / 收起；隐藏后重新显示 |
| `Alt + Shift + V`（默认） | 全局打开剪贴板历史，开启记录后可用 |
| `Ctrl + O` | 添加文件 |
| `Ctrl + V` | 从剪贴板添加文件 |
| `Ctrl + A` | 全选 |
| `Ctrl + C` | 复制选中项，没有选择时复制全部 |
| `Delete` | 移除选中条目，保留原文件 |
| `Esc` | 取消当前拖放；未拖放时收起 |

macOS 将上述 `Ctrl` 换为 `Command`，将 `Alt` 换为 `Option`。隐藏、回到屏幕顶部和退出操作均可通过托盘或灵动岛右键菜单完成。

## 目录结构

- `main.go` 是程序入口，`mygo.json` 是 MyGo 的构建配置。
- `internal/island/` 管理灵动岛界面、窗口、设置和应用状态。
- `internal/shelf/` 和 `internal/preview/` 分别管理文件暂存和预览。
- `internal/nowplaying/`、`internal/audiolevel/` 和 `internal/lyrics/` 分别处理系统媒体、音频频谱和同步歌词。
- `native/macos/` 保存 macOS 音频采集工具源码和签名权限配置。
- `scripts/` 保存构建脚本，`resources/darwin/` 和 `dist/` 分别存放准备好的媒体工具和构建产物。
