# 灵动岛 · Dynamic Island

使用 Go + [MyGo](https://github.com/egoist/mygo) 原生 UI 实现的桌面文件中转岛。界面由 Go 绘制，不需要浏览器、Node.js 或 WebView2。

默认浮在屏幕顶部中央。无暂存文件且媒体未播放时，收起为浅灰磨砂圆球，偶尔眨眼、打哈欠、微笑或看向鼠标。有活动时显示为胶囊。材质使用低遮盖率的珠光色、细微颗粒和柔和边缘高光，保留背景色彩。单击展开，鼠标移开约 200 毫秒后收起。按住收起的灵动岛或展开面板顶部可拖动位置。macOS 和 Windows 的前台应用全屏时，灵动岛与歌词自动隐藏，退出全屏后恢复。

没有暂存文件且媒体未播放时，小球旁显示系统本地时间及当前天气。天气默认按网络 IP 估算位置；可在「设置 → 天气城市」搜索并选择城市，或恢复自动定位。搜索结果以行政区区分同名城市，天气无法获取时继续显示时间。 [天气数据由 wttr.in 提供](https://github.com/chubin/wttr.in) · [城市搜索由 Open-Meteo 提供](https://open-meteo.com/en/docs/geocoding-api) · [城市数据来自 GeoNames](https://www.geonames.org/) · [城市数据许可 CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

## 运行和构建

主要面向 Windows 11 22H2 及以上版本。Windows 使用透明无边框窗口和原生胶囊区域，浅灰渐变、颗粒和高光由应用绘制。macOS 使用 MyGo 的系统玻璃材质，Linux 使用渐变背景。

需要 Go 1.27.3+。`go.mod` 固定 MyGo v0.9.2；开启 `GOTOOLCHAIN=auto` 时，Go 会按需下载所需工具链。

```powershell
go mod download
go run .
```

开发时可运行 `go tool mygo dev`，修改 Go 代码后自动重新构建并启动。在 macOS 上首次开发前运行 `./scripts/build-macos.sh --prepare-media`，开发版与发布版会打包同一份媒体适配器。

构建无控制台窗口的 Windows 程序：

```powershell
.\scripts\build.ps1
```

输出：`dist\DynamicIsland.exe`。也可以直接执行：

```powershell
go build -trimpath -ldflags "-H=windowsgui -s -w" -o dist/DynamicIsland.exe .
```

## 媒体播放

系统有当前媒体时，展开面板会在暂存区上方显示封面、曲名、艺人、播放进度和可用的播放控件。点击或拖动进度条可跳转，具体支持取决于播放器。媒体播放时，收起的胶囊也显示频谱。柱高跟随系统音频，左侧低频，右侧高频。macOS 14.2 及以上首次使用需要允许系统音频录制，只在内存中计算频谱，不保存音频。

- Windows 11 通过系统媒体会话读取和控制播放，使用系统自带的 Windows PowerShell。
- macOS 发布版内置媒体工具，用户打开应用即可使用。用 `./scripts/build-macos.sh` 在装有 Go、Xcode 命令行工具和 CMake 的 Mac 上构建通用版，产物位于 `dist/`。直接用 `go run .` 启动时没有随包媒体工具。

在托盘或灵动岛右键菜单打开「设置」，可为律动柱选择默认蓝灰色、自定义颜色或跟随海报。设置自动保存到与 `shelf.json` 同级的 `settings.json`。

「音乐卡片风格」可在默认的频谱卡片和大封面卡片之间切换，设置中会同步预览。大封面卡片左侧展示专辑封面，右侧显示曲目信息、进度条和播放控件。

收起时，同步歌词以三行显示在胶囊下方，当前句高亮。在 macOS 和 Windows 上，将灵动岛拖到屏幕左侧或右侧边缘松手，灵动岛会收成小圆球，在屏幕内露出一半，歌词显示在朝向屏幕内侧的一边。可在设置里关闭「显示歌词」。在线歌词按曲名和艺人匹配，依次查询 LRCLIB、网易云音乐和 QQ 音乐。也可将 UTF-8 编码的 `歌手 - 歌名.lrc` 放在 `shelf.json` 同级的 `lyrics` 文件夹，程序优先读取本地文件。

## 文件中转

1. 从桌面或资源管理器把文件拖到灵动岛上，松开鼠标完成暂存。支持多个文件和文件夹，重复路径自动去重。暂存区有文件时才显示。
2. 文件以三列紧凑玻璃卡片排列，图片直接显示等比裁剪的缩略图，其他文件显示系统关联的类型图标。每张卡片还显示最多两行文件名、文件类型和大小；超过两行卡片时可在文件区内滚动。把卡片拖到 QQ、微信聊天窗口，或其他支持接收文件的应用。
3. 悬停卡片时显示左上角选择框和右上角移除按钮。勾选多个卡片后，可拖动其中任意选中卡片批量传递；底部“拖出”按钮可拖出选中项，没有选择时拖出全部。
4. 点击复制按钮后，到目标应用粘贴，也可以传递文件。
5. 右键卡片可复制、在文件夹中显示或移除；双击卡片可定位原文件。

右键菜单和托盘菜单可添加文件或文件夹。程序也接受命令行文件路径，例如 `DynamicIsland.exe "D:\资料\说明.pdf"`；重复启动会将路径交给已运行的实例。

缩略图与图标在后台按需加载，仅预加载可见及临近的卡片，内存缓存最多 96 项。Windows 优先使用系统缩略图服务；PNG、JPEG、GIF、WebP、BMP、TIFF 有内置解码回退，SVG 可直接绘制，HEIC、HEIF、AVIF 等依赖系统的缩略图支持。读取失败时显示对应类型的备用图标。重复拖入图片可刷新其缩略图。

暂存区保存的是本地路径引用，不复制文件内容。清空、移除和拖出都不会删除或移动原文件。列表保存在 `%APPDATA%\DynamicIsland\shelf.json`，重新打开时恢复，失效路径会跳过；运行期间失效的路径会在拖出或复制时提示，可手动移除。

文件拖放使用 MyGo 的系统原生接口；Windows 通过 OLE / `CF_HDROP` 传递文件列表。QQ、微信等目标应用是否接受文件、文件夹或多文件，以及是否要求确认发送，由目标应用决定。程序报告“已交给目标应用”表示拖放被接收，不表示消息已经发送。不支持邮件附件等尚未落盘的虚拟文件。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + Space` | 全局展开 / 收起；隐藏后重新显示 |
| `Ctrl + O` | 添加文件 |
| `Ctrl + V` | 从剪贴板添加文件 |
| `Ctrl + A` | 全选 |
| `Ctrl + C` | 复制选中项，没有选择时复制全部 |
| `Delete` | 移除选中条目，保留原文件 |
| `Esc` | 取消当前拖放；未拖放时收起 |

macOS 将上述 `Ctrl` 换为 `Command`。隐藏、回到屏幕顶部和退出操作均可通过托盘或灵动岛右键菜单完成。

## 目录结构

- `main.go` 是程序入口，`mygo.json` 是 MyGo 的构建配置。
- `internal/island/` 管理灵动岛界面、窗口、设置和应用状态。
- `internal/shelf/` 和 `internal/preview/` 分别管理文件暂存和预览。
- `internal/nowplaying/`、`internal/audiolevel/` 和 `internal/lyrics/` 分别处理系统媒体、音频频谱和同步歌词。
- `native/macos/` 保存 macOS 音频采集工具源码和签名权限配置。
- `scripts/` 保存构建脚本，`resources/darwin/` 和 `dist/` 分别存放准备好的媒体工具和构建产物。
